Clear Eyes

Clear Eyes replaces your Home timeline with a cluster view. Every post is grouped by topic and classified by Claude; you see cluster titles, summaries, and counts — never the raw posts. Scroll to pull more posts in.

API

Stored in extension local storage on this machine only, and sent only to api.anthropic.com. Get a key at console.anthropic.com. Consider a dedicated key with a spend limit.
Tuned on claude-sonnet-5. Haiku works but clusters noticeably worse. Any Anthropic model ID works.

Behavior

Media-only posts (no text) are always skipped — there's nothing to cluster.

Clustering prompt

The clustering half of the system prompt (categories are appended automatically). Leave blank to use the built-in default, shown as the placeholder.

Categories

Every post gets exactly one quality category alongside its cluster. Cluster cards show the breakdown; clusters that are mostly hide categories are dimmed as noise. Edit descriptions freely — they are the prompt.
